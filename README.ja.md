フレンドと青魔法のラーニングに出かけようとしたことがあれば、こんな経験があるはずです。「あれ、ダイアモンドバック(Diamondback)をまだ覚えてないのは誰だっけ?」と誰かが聞いても誰も覚えておらず、結局みんなでスペルブックを見比べることになる。BLUnion はその手間を引き受けます。

習得済みのスペルはゲームから直接読み取るので、手入力は不要です。パーティメンバーと進行状況を比較でき、足りないスペルをどこで覚えられるか(モンスター、エリア、判明していれば座標)を表示します。さらに「習得プラン」タブでは、未習得のスペルをモンスターごとにまとめて表示します。1体の敵からグループに必要なスペルを3つ覚えられるなら、1つずつ探さなくてもひと目でわかります。

もともとは自分と数人のフレンドのためのツールでしたが、今ではほかのプレイヤーにも使ってもらえていて、とても嬉しく思っています。ただし趣味で空いた時間に開発しているプロジェクトなので、まだ粗い部分があるかもしれません。

## 機能

- パーティと、その中の青魔道士を自動で検出
- 自分のスペル習得状況を自動で読み取り(Dalamud の `IUnlockState` を使用)
- パーティの平均進行度と「次のおすすめ目標」(一度に最も多くの人の役に立つスペル)を表示する概要ページ
- 複数のプレイヤーを比較し、未習得スペルを必要としている人数の多い順に並べ替え
- 全124種のスペルを収録したスペルブック(習得済み/未習得で絞り込み可能)
- マスクカーニバル全32ステージのロードアウトと、ロール別ロードアウト(タンク、ヒーラー、サブヒーラー、DPS)。必要なスペルのうち何個を習得済みかも表示
- すべてのスペルの入手場所を表示(モンスター、エリアまたはコンテンツ。フィールドの多くの入手場所はマップ座標付き)
- クリックできる場所の表示: コンテンツ名をクリックすると、そのコンテンツを選択した状態でコンテンツファインダーが開きます(「Thornmarch (Hard または Extreme)」のようにまとめられた項目では、先に難易度を選びます)。フィールドのエリア名をクリックすると、対応するエーテライトにテレポしてマップにフラグを立てます。マップアイコンからは、フラグ付きでマップを開くか、マップリンクを自分のチャット欄に表示できます
- 名前またはスペル番号で絞り込み(`58`、`#058` などどちらでも可)
- トーテムでのみ入手できるスペルを非表示にするオプション
- 同じデータセンターの青魔道士を探せるグループファインダー
- 短いエクスポート/インポート用コードで同期。オプションのライブ同期を使えば、コードのやり取りも不要
- UI はドイツ語・英語・フランス語・日本語に完全対応
- プラグインをインストールしたくない人向けの[ブラウザ版](https://letsi-ma.github.io/BLUnion/)

### ゲーム内での動作について

BLUnion はゲームプレイを自動化しません。プラグイン内のクリックで行われる操作は常にひとつだけで、クリックしたときにしか実行されません。

- **コンテンツ名**: コンテンツを選択した状態でコンテンツファインダーを開きます。申請はご自身で行ってください。
- **フィールドのエリア名**: モンスターに最も近いエーテライト(またはそのエリアのメインのエーテライト)へ一度だけテレポし、マップにフラグを立てます。テレポ画面から使う場合と同じくギルがかかり、コンテンツ中・戦闘中・製作中などテレポできない場所ではゲーム側で実行されず、再試行もしません。不要な場合は、設定の「地名クリックでテレポ」をオフにすると、名前はただのテキストになります。
- **マップアイコン**: フラグ付きでマップを開くか、マップリンクを自分のチャット欄に表示します。誰かに送信されることはありません。

## 同期の仕組み

方法は2つあり、好きな方を選べます。

標準はコードです。自分の状況を短い `BLU:...` コードとしてエクスポートし、パーティチャットや Discord など好きな方法で送ります。初期設定では、チャットに流れてきたコードをプラグインが自動で読み取って比較に追加するので、パーティなら基本的に「全員が一度エクスポートを押すだけ」です。この機能は設定でオフにできます。サーバーは使わず、すべて自分の PC 内で完結します。

設定でライブ同期をオンにすると、スペルの習得状況が小さなサーバーにアップロードされ、パーティ内のほかの青魔道士の状況もプラグインが自動で取得します。コードのやり取りは不要になり、新しく覚えたスペルもすぐにほかのメンバーに反映されます。

Dalamud プラグインを使わない場合は、[ブラウザ版](https://letsi-ma.github.io/BLUnion/)で同じことができます。コードの作成、ほかの人のコードの読み込み、グループファインダーの利用が可能です。

## グループファインダー

ライブ同期を利用した機能です。自分のデータセンターの公開リストに、短いメモ、普段遊ぶ時間帯(朝・夜・週末など)、募集人数、ラーニングしたいスペルを登録できます。ほかのプレイヤーはリストを閲覧し、自分に必要なスペルで絞り込んで、そのグループに自分が貢献できるスペルとまだ足りないスペルをすぐに確認できます。ワンクリックでそのプレイヤーを自分の比較に追加できます。

オンライン状況の共有をオンにすると、リストを見ているほかのプレイヤーに、今オンラインかどうかが表示されます。

現在、グループファインダーに登録できるのは個人のみで、グループの募集は無効になっています。

自分で登録しない限り何も公開されず、登録はいつでも削除できます。

グループファインダーのキャラクター名は認証されていないため、他人の名前で登録することも技術的には可能です。偽の登録や自分の名前の悪用を見つけた場合は、[Discord](https://discord.gg/uGW7kBG67) で報告していただければ削除します。

## 保存されるデータ

ライブ同期またはグループファインダーを使う場合のみ関係します。使わない場合、データが PC の外に出ることはありません。

- キャラクター名、ワールド、データセンター
- 習得済みのスペル(コンパクトなビットマスク形式)
- グループファインダーに登録した場合: メモ、遊ぶ時間帯、募集人数、目標スペル
- ハッシュ化された編集用トークン(自分だけがプロフィールを変更・削除できるようにするため)
- 「オンライン状況を共有」をオンにし(初期設定はオフ)、グループファインダーに登録している場合のみ: オンラインかどうかと最終オンライン時刻(15分単位で丸め)。この情報は自分のプラグインからのみ送信されます(ログイン時、ログアウト時、プレイ中は1時間に1回)。このデータは、プロフィールの削除時、オプションをオフにしたとき、または30日間信号がなかった場合に削除されます

プラグインを初めて開いたときに、ライブ同期を使うか手動のコードのみにするかを選べます。この設定(とオンライン状況)は、設定画面からいつでも変更できます。

プロフィールは90日間更新がないと自動的に削除されます。設定の「自分のプロフィールを削除」を使えば、すぐに削除できます。名前はゲームと照合されていないため、悪用(自分の名前で作られた身に覚えのないプロフィールなど)は [Discord](https://discord.gg/uGW7kBG67) で報告できます。バックエンドは Cloudflare Worker で、コードは [`worker/`](worker/) にあります。

## インストール方法

カスタムプラグインリポジトリを使うのが一番簡単です。

1. ゲーム内で `/xlsettings` → Experimental → Custom Plugin Repositories を開きます
2. `https://raw.githubusercontent.com/letsI-MA/BLUnion/main/pluginmaster.json` を追加します
3. 保存すると、`/xlplugins` の利用可能なプラグインに BLUnion が表示されます(アップデートも自動で届きます)

自分でビルドしたい場合は、リポジトリをクローンして `dotnet build` を実行し、Dalamud の Dev Plugin Locations に生成された DLL を指定してください。

どちらの場合も、`/blunion` でウィンドウが開きます。

## データの出典

スペル名、モンスター名、地名は、選択した表示言語でゲームデータから実行時に直接読み込んでいます。出典の詳細は[英語版 README](README.md#where-the-data-comes-from) をご覧ください。

## Discord

コミュニティ用の Discord サーバーがあります: https://discord.gg/uGW7kBG67

グループファインダーに公開された登録には、4つの地域チャンネル(北米、ヨーロッパ、日本、オセアニア)のいずれかにカードが自動で作成されます。スラッシュコマンドも2つあります。`/blunion browse` で Discord から直接リストを確認でき、`/blunion online` でデータセンター内の現在オンラインのプレイヤーを確認できます(オンライン状況を共有している登録のみ)。現在 Discord は閲覧専用で、Discord から登録することはできません。

## 既知の制限

- フィールドの入手場所のマップ座標は手作業で管理しているため(ゲームデータからは取得できません)、一部の場所ではまだ座標がありません
- グループファインダーの新しい登録がほかのプレイヤーに表示されるまで、最大1分ほどかかることがあります(保存の仕組みによるもので、不具合ではありません)
